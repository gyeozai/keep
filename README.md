# Keep Your Mind

A sleek and modern diary built with Flask and SQLite, featuring markdown format and a smooth drag-and-drop interface.

[Check out the DEMO](https://youtu.be/WZRrCnWAkqw)

## How to run

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```
